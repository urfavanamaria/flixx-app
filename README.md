# Flixx 🎬

A sleek movie and TV show info app built with vanilla JavaScript. It fetches data from a public API and displays trending titles, ratings, and descriptions in a responsive layout.

🔗 [Live Demo](https://flixx-app-blue.vercel.app)

## 🚀 Features

- Browse trending movies and TV shows
- View ratings, release dates, and overviews
- Responsive design for mobile and desktop
- Clean UI with dynamic content loading

## 🛠️ Tech Stack

- JavaScript (ES6+)
- HTML5 & CSS3
- TMDB API (or similar)
- Optional: Bootstrap or custom styling

## 📚 Based On

Inspired by Brad Traversy's JavaScript course and adapted to include custom styling and layout improvements.

## 📦 Installation

1. Clone the repo  
   `git clone https://github.com/urfavanamaria/flixx-app.git`
2. Add your API key (if needed) in the config file
3. Open `index.html` in your browser
